# Кабиторий

**Кабиторий** — личный кабинет пользователя (обучающегося / сотрудника / контрагента)
образовательной организации с возможностью запроса услуг через МФЦ. Разрабатывается
как отдельный сервис в экосистеме aplicon-ru наряду с edu-framework.

> ⚠ Карточка создана в раунде разбора Универкон-архива на основе упоминания в
> `docs/about/api.md`. Детальное описание — по мере развития проекта; автор карточки
> может дополнить недостающие поля.

## Что делает

По исходному описанию — «API для работы с личным кабинетом пользователя с возможностью
запроса услуг через МФЦ». Ожидается, что реализует:

- Личный кабинет обучающегося: доступ к учебному процессу, оценкам, приказам
- Электронный документооборот с ОО через ЕПГУ / Госключ
- Интеграцию с МФЦ для получения справок и документов

## Предполагаемая связь с фреймворком

| Домен | Что реализуется |
|---|---|
| **D05** (контингент) | Личный кабинет обучающегося — витрина состояния, приказов, документов |
| **D12** (цифровая инфраструктура) | Интеграция с ЕПГУ, ЕСИА, Госключ, МФЦ |

Возможно также участие D04, D09, D11 — уточнить по мере проработки.
