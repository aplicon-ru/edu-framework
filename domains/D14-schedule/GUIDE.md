# D14 · Руководство по работе с доменом

## Главное разграничение: D14 vs D04

| Вопрос | D14 | D04 |
|---|---|---|
| Что должно произойти? | ✓ | — |
| Что произошло? | — | ✓ |
| Кто должен быть на занятии? | ✓ (именованный отбор) | — |
| Кто был на занятии? | — | ✓ (снимок состава, записи) |
| Нагрузка преподавателя? | ✓ (агрегат) | — |

## Именованный отбор: правило поверх D05.Группа

Именованный отбор — не дубль группы D05, а **правило** поверх неё. D05 уже владеет
сущностью `Группа` с типом (основная / подгруппа / поток / элективная) и связью
`Членство в группе` (M:N во времени). Именованный отбор ссылается на одну или несколько
групп D05 и говорит: «состав занятия = объединение активных членств в этих группах на
дату занятия, с фильтром».

**Хранится:** имя, срок действия, правило (какие группы D05, какой фильтр).
**Не хранится:** результат вычисления (состав обучающихся). Он вычисляется при создании
журнала D04 против актуальных `D05.Членство в группе` и замораживается там.

**Почему не хранить состав.** При переводе студента (приказ D05 → изменение членства)
следующий журнал автоматически отразит изменение. Если бы отбор хранил список — пришлось
бы обновлять вручную; это нарушает единственный источник правды.

## Типовые ошибки

**Дублировать D05.Группа именованным отбором.**
Если у группы уже есть тип «поток» или «элективная» в D05, не создавайте отдельный отбор
«поток» с тем же составом — просто ссылайтесь на группу D05. Именованный отбор нужен там,
где состав получается **комбинацией** групп или требует **фильтра**.

**Хранить в отборе снимок состава.**
Отбор хранит правило, не состав. Снимок замораживается в D04 при создании журнала.

**Создавать учебное событие D04 напрямую, минуя D14.**
Учебные события должны порождаться расписанием. Событие без запланированного занятия —
нетиповой сценарий (внеплановое занятие); требует отдельного основания и документа.

**Смешивать перенос и редактирование.**
Перенос занятия — это пара событий (исходное → [Перенесено], новое → [Запланировано]).
Не редактирование даты в существующей записи: это скрывает историю.

**Считать нагрузку из факта D04, а не из плана D14.**
Нагрузка ППС — это плановый показатель, считается из расписания. Фактическое проведение
(D04) может отличаться от плана; для учёта отработок — отдельный процесс.

## Что делать при отмене занятия

1. Перевести запланированное занятие в [Отменено].
2. Учебное событие в D04 не создаётся (если занятие отменено до старта).
3. Если занятие уже стартовало (D04 создан) — отмена оформляется сторно в D04.
4. Нагрузка пересчитывается автоматически (отменённые занятия не входят в агрегат).
