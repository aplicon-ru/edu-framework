# D11-P01: Ведение раздела «Сведения об образовательной организации» (`/sveden/`)

**Домен:** D11 · **Применимость:** ВУЗ, СПО, ДО, ДПО, Аспирантура
**Статус:** draft

## Назначение

Обеспечить и поддерживать обязательный раздел официального сайта ОО «Сведения об
образовательной организации» в структуре, составе и микроразметке, установленных
Приказом Рособрнадзора № 1493, и не допустить расхождения между опубликованными
сведениями и фактическими данными организации (лицензия, программы, кадры).

## Нормативное основание

- ФЗ-273, ст. 29 — информационная открытость образовательной организации
- ПП РФ от 20.10.2021 № 1802 — Правила размещения информации на официальном сайте ОО
- Приказ Рособрнадзора от 04.08.2023 № 1493 (в ред. № 1353 от 03.07.2025, вступила
  в силу 01.03.2026) — структура раздела, 14 подразделов (Табл. 3.1), микроразметка
- Методические рекомендации Рособрнадзора v9.0.0 — словарь `itemprop` по подразделам,
  см. [`standards/sveden/`](../../../standards/sveden/)

## Входы

- Каноническая модель данных организации по
  [`standards/sveden/schema/instance.schema.yaml`](../../../standards/sveden/schema/instance.schema.yaml):
  `org`, `subdivisions`, `programs[]`, `teachers[]`, `infra`, `docs`, `budget`
- Действующие лицензия и (при наличии) свидетельство об аккредитации (D02)
- Электронные версии документов: устав, ЛНА, учебные планы, РПД, отчёт о
  самообследовании (D02, D06, D13)

## Шаги

1. **Определить применимость подразделов.** Для каждого из 14 подразделов
   `vocab/base.yaml` оценить применимость по существу для данной ОО (например,
   `grants` — стипендии — неприменим для коммерческого ДПО без бюджетных мест;
   `inter` — международное сотрудничество — неприменим при отсутствии договоров).
   Неприменимые подразделы **не исключаются из структуры**, а заполняются «отсутствует».
2. **Собрать каноническую модель данных.** Свести `org.*`, `programs[]`, `teachers[]`,
   `infra`, `docs.*`, `budget` по схеме `instance.schema.yaml`. Источники — D02
   (лицензия), D05/D06 (программы, численность, УП/РПД/ФОС), D07 (педсостав), D09
   (бюджет, платные услуги).
3. **Сгенерировать/разметить страницы.** Для каждого подраздела — страница по
   фиксированному URL (`/sveden/<slug>/`). Каждое поле словаря → элемент с
   `itemprop` из `vocab/base.yaml`. Пустое обязательное поле → текст «отсутствует»
   (правило `_global.yaml` → `missing_value`), `itemprop` сохраняется.
4. **Опубликовать электронные документы (ЭД).** Для полей `*DocLink`/`*El`
   (например, `licenseDocLink`, `educationPlan`, `educationRpd`, `reportEduDocLink`)
   — обеспечить доступность ссылок на актуальные версии документов.
5. **Добавить версию для слабовидящих.** Каждая страница подраздела — с элементом
   `itemprop="copy"` (требование `a11y`, см. срок действия в `_global.yaml`).
6. **Самопроверка («чек-лист соответствия»).** Имитировать обход АИС «Мониторинг»:
   по каждому подразделу — все обязательные поля присутствуют и размечены
   `itemprop`? Зафиксировать результат (`ЧекСоответствия`).
7. **Поддерживать актуальность.** При изменении источника (новая лицензия, новая
   программа, изменение состава кадров, новая редакция ЛНА) — обновить
   соответствующие поля канонической модели; повторная разметка не требуется,
   если структура `itemprop` не изменилась.
8. **Реагировать на новую редакцию приказа.** При выходе дельты к Приказу № 1493 —
   добавить новые подразделы/поля поверх `vocab/base.yaml` (append-only); не
   переписывать существующую разметку.

## Выходы / артефакты

- Опубликованный раздел `/sveden/` из 14 подразделов по фиксированным URL
- Версии для слабовидящих по каждому подразделу
- Чек-лист соответствия (по каждому подразделу: поле → присутствует/размечено)
- Перечень ЭД с действующими ссылками

## Участники

| Роль | Действие |
|---|---|
| Веб-администратор / ИТ | Публикует страницы, размечает `itemprop`, поддерживает доступность 24/7 |
| Приёмная комиссия / отдел по связям с общественностью | Сводит каноническую модель данных, проверяет полноту |
| Юридический отдел | Подтверждает актуальность ссылок на ЛНА и устав |
| Учебно-методическое управление | Предоставляет ЭД программ (УП, РПД, ФОС) из D06 |
| Ответственный за лицензирование (D02) | Предоставляет данные лицензии/аккредитации |

## Типовые ошибки

- **Подраздел исключён из навигации** как «неприменимый» — структура раздела
  фиксирована приказом целиком; правильно — заполнить «отсутствует», не убирать
  страницу.
- **Пустое поле без `itemprop`** — для робота АИС «Мониторинг» это означает «поле
  не размечено», а не «поле пустое»; разметка должна сохраняться даже при пустом
  значении.
- **Расхождение данных лицензии на сайте и в пакете D02** (например, после
  переоформления лицензии обновили пакет, но не сайт) — нарушение инварианта
  «источник данных один» (см. data-model/entities.md).
- **Ссылка на ЭД устарела** (документ заменён новой версией, ссылка не обновлена) —
  раздел формально размечен, но содержит недостоверные сведения.
- **Версия для слабовидящих не на всех страницах** — требование `a11y: copy`
  распространяется на каждый подраздел, не выборочно.
