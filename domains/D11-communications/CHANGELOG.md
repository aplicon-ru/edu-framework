# CHANGELOG · D11 Коммуникации и публичность

## [0.1.0] — 2026-06-11

### Добавлено
- Структура домена: README, GUIDE, metadata.yml, processes/, data-model/
- D11-P01: ведение раздела «Сведения об образовательной организации» (`/sveden/`) —
  определение применимости подразделов, сборка канонической модели данных,
  публикация и микроразметка, самопроверка, реакция на новые редакции приказа
- data-model/entities.md: модель проекции (СведенияРаздел, ПолеРазметки,

- GUIDE.md: карта источников данных по подразделам, правило «применим/неприменим»

### Архитектурное решение
D11 — новый домен, выделен под обязательство ст. 29 ФЗ-273 (информационная
открытость), ранее не покрытое ни одним доменом. D11 не вводит собственную модель
данных — проецирует каноническую модель организации
([`standards/sveden/schema/instance.schema.yaml`](../../standards/sveden/schema/instance.schema.yaml))
в структуру `/sveden/` по словарю
[`standards/sveden/vocab/base.yaml`](../../standards/sveden/vocab/base.yaml).

### Источники и авторство
- Структура раздела `/sveden/`, словарь микроразметки (v9.0.0) и каноническая схема
  данных — из рабочих каркасов лицензирования ДО/ДПО (handoff, iMironRU, 2026),
  вынесены в `standards/sveden/`.
- Структурирование домена D11: Claude Sonnet 4.6.

  `standards/sveden/schema/instance.schema.suggestions.yaml`.
