# Модель данных — D13: Качество и отчётность

## Обзор

Реестр отчётности — набор записей «что сдаём»; календарь и журнал сдачи — «когда и как это идёт в конкретной ОО».
Машиночитаемая форма реестра — [standards/reporting/](../../../standards/reporting/) (поля ниже совпадают с ключами `registry.json`).

## Сущности

| Сущность | Описание | Ключевые поля |
|---|---|---|
| **Отчёт (вид)** | Позиция реестра: что и кому сдаётся | `id`, `section`, `name`, `applies_to`, `recipient`, `channel`, `kind`, `periodicity`, `deadline`, `legal_basis`, `contains_financial_block` |
| **Подача (способ)** | Как подаётся | `submission[]`, `system`, `format`, `signature`, `form_code` |
| **Форма** | Бланк, шаблон или онлайн-форма | `forms[]`: `name`, `code` (ОКУД/КНД), `act_ref`, `kind`, `template_url`, `paper_print_required` |
| **Основание** | Нормативный акт | `legal_basis[]` (акт, редакция, с какого периода) |
| **Проверка** | Достоверность записи | `verification`, `format_check` (`primary` / `secondary` / `inferred` / `unresolved`), `sources` |
| **Срок (календарь)** | Дата или окно сдачи | `calendar.json`: `id`, `month`, `when`, `what`, `who`, `note` |
| **Экземпляр отчёта (подача за период)** | Хранится в ИС ОО, не в реестре | организация, вид отчёта, период, редакция бланка, статус, дата сдачи, подтверждение |

## Значения полей

| Поле | Значения |
|---|---|
| `section` | `STAT` статистика · `ADM` приём · `DOC` документы и контингент · `SELF` самообследование и мониторинги · `GIA` итоговая аттестация · `LIC` лицензирование и аккредитация · `REL` смежные направления · `MED` медицинские вузы |
| `applies_to` | `VO` · `SPO` · `DO_PRE` · `DO_ADD` · `DPO` (соответствие типам фреймворка — [standards/reporting/README.md](../../../standards/reporting/README.md)) |
| `kind` | `periodic` · `event` · `continuous` |
| `submission[]` | `fsn_web` · `fis_web` · `fis_api` · `gosuslugi` · `vendor_lk` · `smev` · `org_site` · `paper` · `email` · `tks` · `other` |
| `signature` | `ukep` · `mchd` · `ukep_mchd` · `none` · `unknown` |
| `forms[].kind` | `blank` · `xml_template` · `online_form` · `free_form` · `none` |

## Рекомендуемые статусы экземпляра отчёта

Черновик → Заполнен → Проверен → Утверждён → Сдан → Принят или Отклонён. Для корректирующей подачи — отдельный экземпляр с номером корректировки.
