# CHANGELOG · D05 Управление контингентом

## [Не выпущено]

### Изменено (сцепка с нормой D06, шаг 2)

- Введены сущности **Набор** (когорта), **Приёмная кампания**, **КЦП**.
- **Группа** переведена в организационный срез; членство стало «многие-ко-многим во времени»
  (новая связь «Членство в группе»). Поле `Обучающийся.group_id` удалено.
- Добавлено `Обучающийся.nabor_id`; `program_id` стал **производным** от набора (Набор →
  версия ОПОП), перестал быть самостоятельным источником истины.
- **Траектория** зафиксирована как представление (план из D06 + факт из D04), не хранимая сущность.
- `D06` перенесён из `related_to` в `depends_on` — после привязки `opop_versiya_id`
  зависимость стала настоящей.
- ⚠ Миграция: текущие `group_id` → членство с `s = enrollment_date`, `tip = основная учебная`;
  `program_id` пометить производным, данные не трогать.
