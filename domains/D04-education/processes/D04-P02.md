# D04-P02: Академическая задолженность — возникновение и ликвидация

**Домен:** D04 · **Применимость:** ВУЗ, СПО, ДПО, Аспирантура
**Статус:** draft

## Назначение

Описывает жизненный цикл академической задолженности: вычисляемое состояние с юридически
нагруженным таймером и лимитом попыток. Цель — дать студенту законную возможность ликвидации,
защитить ОО от незаконного автоматического отчисления (когда слот не предлагался), и
зафиксировать основание для отчисления если ликвидация невозможна.

## Нормативное основание

- ФЗ-273, ч. 5 ст. 58 — повторная промежуточная аттестация: **не более 2 раз**, в пределах
  **1 года** с момента образования задолженности, с исключением периодов болезни,
  академотпуска, отпуска по БиР. ⚠ Сверить формулировку вручную перед PR.

## Входы

- Отрицательная запись ведомости по обязательству уровня дисциплины (из D04-P01).
- Снимок периодов-исключений обучающегося из D05 (академотпуск, болезнь, БиР).
- Учётная политика: лимиты попыток, сроки, порядок формирования комиссии.

## Шаги

1. Ведомость даёт отрицательную запись по обязательству уровня дисциплины; дата сессии прошла
   → задолженность **вычисляется** (не создаётся объект). Система сигнализирует.
2. Запускается таймер = дата возникновения + периоды-исключения (снимок из D05). При новом
   событии-исключении (новый академотпуск и т.п.) таймер пересчитывается.
3. Кафедра формирует **график пересдач** — предложенный слот является доказательством
   исполнения организационной обязанности ОО.
4. Попытка 1 (обычная пересдача): обычная ведомость; положительная запись → **[Ликвидирована]**;
   отрицательная или неявка — засчитывается как использованная попытка.
5. Попытка 2 (комиссионная): тип ведомости определяется автоматически по номеру попытки;
   положительная запись → **[Ликвидирована]**; отрицательная или неявка → **[Исчерпана]**.
6. Если срок истёк И есть зафиксированный факт неявки/отказа на предложенный слот →
   **[Просрочена]**.
7. **[Исчерпана]** или **[Просрочена]** → основание для отчисления: система выдаёт сигнал,
   ответственный сотрудник готовит документ. Автоматического отчисления нет.

## Выходы / артефакты

- Исходы задолженности: **[Ликвидирована]** / **[Исчерпана]** / **[Просрочена]**.
- Протокол комиссионной ведомости (попытка 2).
- Сигнал для D05 об основании к отчислению (при [Исчерпана]/[Просрочена]).

## Участники

| Роль | Действие |
|---|---|
| Кафедра | Формирует график пересдач; проводит комиссию (попытка 2) |
| Обучающийся | Является на пересдачи; неявка фиксируется и засчитывается |
| УМУ | Контролирует сроки, формирует сигналы для ответственных |
| Учебный отдел / D05 | Получает основание для приказа об отчислении |

## Типовые ошибки

- **Автоматическое отчисление** по истечении срока без зафиксированной неявки — нарушение
  ч. 5 ст. 58 ФЗ-273. Отчисление — документ, не автомат.
- **Не предложен слот** — задолженность не переходит в [Просрочена] при отсутствии записи
  об отказе студента. Это организационный долг ОО.
- **Периоды-исключения игнорируются** — таймер отсчитывается без учёта академотпуска или
  болезни; нарушение права студента.
- **БРС пересчитывается при пересдаче** — пересдача закрывает обязательство уровня
  дисциплины, не пересчитывает накопленный рейтинг текущего контроля.
