# CHANGELOG · standards/sveden

## [0.1.0] — 2026-06-11

### Добавлено
- `vocab/base.yaml` — словарь микроразметки `/sveden/`, выверен против Методических
  рекомендаций Рособрнадзора v9.0.0: все 14 подразделов Табл. 3.1 размечены
  (`status: verified`).
- `vocab/_global.yaml` — общие правила: стиль атрибутов, `missing_value: "отсутствует"`,
  требование версии для слабовидящих (`a11y: copy`), сверка через АИС «Мониторинг».
- `schema/instance.schema.yaml` — каноническая схема данных организации
  (org / subdivisions / programs / teachers / infra / docs), с разметкой `used_by`
  для проекций `license` (D02) и `sveden:<подраздел>` (D11).
- `schema/instance.schema.suggestions.yaml` — сводка полей с `from: "TBD"` из
  `base.yaml`: предложения путей в `instance.schema.yaml`, ещё не утверждённые.

### Решённые вопросы выверки (зафиксированы в base.yaml)
- Нотация итератора: коллекция на группе (`[]`), `<singular>.path` на полях.
- `staff[]` → `teachers[]` / `teacher.*` (подраздел `employees` → `teachingStaff`).
- Структура ЛНА — плоские `docs.*` (не коллекция), адресуется по itemprop напрямую.
- ЭИОС → главный itemprop `comNet` (`infra.platform.url`); платформа также в `infra.eor[]`.
- `a11y: "copy"` сохранён со сроком до 01.09.2025 (требует эмпирической проверки
  в АИС «Мониторинг»; при отмене требования — снять по всему словарю).

### Дальнейшие шаги
1. Свести оставшиеся `from: "TBD"` в `base.yaml` с путями из `instance.schema.suggestions.yaml`.
2. Прогнать рендер `/sveden/` на тестовой инстанс-модели (см. D11-P01).
3. Эмпирически проверить актуальность требования `a11y: copy` в АИС «Мониторинг».
