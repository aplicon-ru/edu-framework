# Исходные тексты ФГОС

Тексты стандартов в формате Markdown, полученные с официального сайта [fgos.ru](https://fgos.ru) (в первой строке каждого файла — адрес страницы-источника). Из них собраны машиночитаемые файлы в [`../data/`](../data/): имя исходника указано в каждом JSON в поле `provenance.source_file`.

- Это официальные тексты федеральных нормативных актов; они приведены как первоисточник для проверки извлечённых данных.
- Для 22 стандартов ординатуры 3++ (2021–2025 гг.) исходниками служат сканы PDF с [fgosvo.ru](https://fgosvo.ru/fgosvo/index/30), в репозиторий они не включены (адрес — в `meta.source_url`).
- Ссылайтесь на актуальную редакцию на официальном сайте: тексты здесь — снимок на дату выгрузки.
