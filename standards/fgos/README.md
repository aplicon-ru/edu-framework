# ФГОС в машиночитаемом формате

Этот раздел содержит Федеральные государственные образовательные стандарты
в формате JSON — для использования в ИС, скриптах валидации и автоматической
генерации документов (ОПОП, учебные планы, матрицы компетенций).

---

## Зачем это нужно

ФГОС в PDF — документ для чтения. ФГОС в JSON — источник данных для:
- автоматической проверки соответствия ОПОП требованиям стандарта
- генерации матрицы компетенций
- валидации рабочих программ дисциплин
- импорта в ИС при создании новой образовательной программы
- сравнения версий стандартов при актуализации программ

## Структура

```
fgos/
├── README.md               ← этот файл
├── schema/
│   └── fgos.schema.json    ← JSON Schema (валидирует все data/*.json)
├── data/                   ← машиночитаемые ФГОС (JSON), сейчас 164 файла
└── sources/                ← исходные тексты (Markdown, fgos.ru) для проверки данных
```

---

## Именование файлов

Формат: `FGOS-<ТИП>-<КОД_УГСН>-<ГОД>.json`

| Часть | Значение | Пример |
|---|---|---|
| ТИП | VO / SPO / OO / DPO | `VO` |
| КОД_УГСН | Код направления через точки | `44.03.04` |
| ГОД | Год приказа об утверждении | `2022` |

Пример полного имени: `FGOS-VO-44.03.04-2022.json`

---

## Схема (fgos.schema.json)

Схема описывает четыре обязательных блока:

| Блок | Содержание |
|---|---|
| `meta` | Реквизиты: тип, уровень, код УГСН, номер и дата приказа |
| `program` | Характеристики программы: квалификация, формы, сроки, объём в з.е. |
| `competencies` | УК, ОПК, ПК — код + формулировка |
| `structure` | Блоки программы с объёмом в з.е. |

Дополнительный блок `requirements` — кадровые и МТБ-требования (опционально).

## Что уже есть: медицинские и смежные ФГОС ВО (пакет из проекта «Классификатор дисциплин медицинских вузов»)

В `data/` добавлены 163 стандарта высшего образования: ординатура (94 стандарта редакции 2014 г. и 22 стандарта 3++ 2021–2025 гг.), специалитет (23), магистратура (11), бакалавриат (8), аспирантура ФГОС 2014 г. (5), — коды 30–34, 37 и смежные (06.*), ~2 800 компетенций.

**Как получены.** Текст стандарта (Markdown с fgos.ru либо скан с fgosvo.ru) передан модели Claude Sonnet 5.5 со строгой схемой ответа; затем автоматическая проверка по тексту источника:

- формулировка каждой компетенции найдена в тексте дословно (для сканов — по порядку слов в OCR-тексте, порог 0,9);
- цитаты-основания (`provenance.evidence`) найдены в тексте;
- сумма блоков Б1–Б3 сопоставлена с общим объёмом.

Результат проверки лежит в `provenance.verification` каждого файла. УК/ОПК 301 из 301 сопоставимых формулировок совпали с независимым разбором тех же текстов регулярными выражениями.

**Что учесть**
- Нормативка требует проверки человеком (правило репозитория для AI-вклада): значения без прямого указания в тексте оставлены `null` — это `meta.effective_date` (в большинстве приказов явной даты нет) и `program.qualification` (часто не названа в тексте).
- Добавлен `meta.level = residency` (ординатура), в схеме — см. коммит «схема».
- ОПК и УК ординатуры 3++ различаются по специальностям и годам издания — у каждого стандарта собственный список.
- Помимо обязательных блоков схемы файлы содержат `competencies.general_cultural` (ОК — для ФГОС 3+), `program.duration_details`, `program.max_credits_per_year` и блок `provenance` (источник, метод, результаты проверки). Эти поля необязательные.
- Сведения об особенностях источника: в ФГОС 31.08.61 код ПК-6 повторён с двумя разными формулировками (так напечатано в тексте стандарта).
- Для 6 формулировок УК/ОПК в сканах 3++ сходство с OCR ниже порога и нужна проверка глазами: перечень — в `provenance.verification.comp_low_similarity` файлов 31.08.05, 31.08.08, 31.08.11, 32.08.12 (и ещё нескольких, где расхождение объяснено шумом распознавания).
- Валидация: `python tools/validate-fgos.py --all`.

## Как добавить новый ФГОС

1. Откройте официальный текст стандарта на [fgosvo.ru](https://fgosvo.ru) или [consultant.ru](https://consultant.ru)
2. Скопируйте `data/_EXAMPLE.json` как шаблон
3. Заполните все обязательные блоки по тексту стандарта
4. Запустите валидацию
5. Откройте PR — один ФГОС = один PR

**Важно:** проверяйте актуальность стандарта. Некоторые ФГОС имеют изменения,
вносимые отдельными приказами. Указывайте в `meta.source_url` ссылку на
актуальную редакцию, в `meta.order_date` — дату последних изменений.
