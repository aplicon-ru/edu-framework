# Реестр регламентной отчётности

Машиночитаемый реестр отчётов и передач данных образовательных организаций (домен [D13](../../domains/D13-quality/)).
Версия данных: `registry.json` → `version`; актуальность → `as_of`.

| Файл | Что внутри |
|---|---|
| `registry.json` | 69 позиций: получатель, канал, срок, основание, способы подачи, формат, подпись, формы и бланки, статус проверки |
| `calendar.json` | Календарные сроки (месяц, день или окно) со ссылками на `id` реестра |
| `schema/registry.schema.json` | JSON Schema реестра |

Проверка: `python tools/validate-reporting-registry.py`

## Соответствие типов ОО

| Тип фреймворка | Коды реестра |
|---|---|
| `vuz` | `VO` |
| `spo` | `SPO` |
| `do` | `DO_PRE` (дошкольные) и `DO_ADD` (дополнительное образование детей) |
| `dpo` | `DPO` |
| `aspirantura` | отдельного кода нет: применимые позиции вузов и ДПО (например, `STAT-1NK`, `REL-DISSOVET-*`) |

Школы (общеобразовательные организации) в реестр не входят.

## Статусы проверки

| Значение | Смысл |
|---|---|
| `verified_2026-10` | Подтверждено по первоисточнику |
| `verified_secondary_2026-10` | Сверено по зеркалам правовых баз (КонсультантПлюс, Гарант и др.); ⚠ сверить с pravo.gov.ru |
| `to_verify` | Не подтверждено |

`format_check.status` оценивает отдельно способы подачи, формат и подпись: `primary`, `secondary`, `inferred`, `unresolved`.

## Ограничения

- Реестр собран на дату `as_of`; формы Росстата и ведомственные порядки меняются почти каждый год.
- Часть позиций (например, `STAT-1PK`, `REL-DISSOVET-ANNUAL`, `REL-MIL-DEFERMENT`) содержит оговорки в `notes`.
- Данных конкретных организаций реестр не содержит.
