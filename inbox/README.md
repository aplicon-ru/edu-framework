# Inbox — материалы для распределения

Папка для сырых материалов, которые ждут разбора и распределения по доменам, процессам,
best-practices, дорожным картам.

**Цель — держать эту папку пустой.** Всё, что здесь лежит, — это долг: непонятое, нераспределённое,
неинтегрированное. Раз в неделю (или по мере накопления) inbox разбирается.

## Что кладём

- Концепции, черновики, заметки, которые могут повлиять на модель фреймворка
- Промты, ТЗ, инструкции, которые сгенерировали контент, требующий сохранения
- Внешние источники (PDF, MD, ZIP), которые нужно проанализировать
- Результаты обсуждений, которые ещё не оформлены как best-practice или дорожная карта

## Что не кладём

- **Данные конкретных ОО** — репозиторий публичный (правило CLAUDE.md)
- **Чувствительные документы** (внутренние ЛНА клиентов, коммерческие тайны) — обрабатывай оффлайн
- **Файлы более 5 МБ** — используй ссылку на внешнее хранилище + memo в inbox

Если сомневаешься — не клади. Спроси или обработай оффлайн.

## Именование

Плоская структура, префикс — дата ISO:

```
inbox/2026-07-04-concept-main-v2.pdf
inbox/2026-07-04-concept-main-v2.memo.md
inbox/2026-06-15-schedule-brainstorm.md
```

Для крупных пакетов — папка с датой:

```
inbox/2026-07-04-academic-handoff/
  ├── source.zip
  ├── notes.md
  └── memo.md
```

**Memo обязателен** для нетривиальных материалов — описание, откуда взялось, что с этим
делать, кто ответственный. Формат:

```markdown
# Memo: <название>

**Дата попадания:** 2026-07-04
**Источник:** @user / автор / URL
**Тип:** концепция / промт / доклад / рецензия / иное
**Предположительная судьба:** best-practice в DXX / дорожная карта / отказ / …
**Ответственный:** @iMironRU

## Что это

<Одна-две фразы: что за материал, зачем сохраняется>

## Что с этим делать

<Гипотеза: куда распределить, что извлечь>
```

## Ритуал разбора

Раз в неделю (или по накоплении 3–5 файлов):

1. Пройтись по каждому файлу
2. Для каждого — решить:
   - **интегрировать** — извлечь идеи в домены, зафиксировать через PR
   - **отложить** — переместить в `inbox/backlog/` с явным memo о причине
   - **выбросить** — удалить (актуально для устаревших промтов)
3. После разбора — папка должна быть пуста (кроме `backlog/` и `README.md`)

## Что не является inbox

- `implementations/` — каталог реализующих фреймворк сервисов (не сырьё)
- `standards/` — машиночитаемые стандарты (готовый результат)
- `domains/DXX/best-practices/` — оформленные best-practices (готовый результат)
