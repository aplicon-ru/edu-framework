# inbox/archive/ — материалы после разбора

Здесь лежат материалы, **прошедшие разбор и распределение** по доменам фреймворка.
Хранятся для истории — чтобы всегда можно было увидеть, из какого источника
выращена конкретная концепция домена.

## Отличие от `inbox/backlog/`

- **`inbox/`** — материал ждёт разбора
- **`inbox/backlog/`** — материал сознательно отложен (не будем разбирать сейчас,
  но и не выбрасываем)
- **`inbox/archive/`** — материал разобран, содержимое распределено по доменам,
  оригинал сохранён для истории

## Как найти, во что был превращён источник

Каждый разобранный источник должен иметь связанное memo (в самом архиве или в
CHANGELOG соответствующего домена) со ссылками на PR / коммиты / файлы, куда
пошёл контент.

## Правила ведения

1. Файлы **никогда не редактируются** после архивации — иначе теряется след истории.
2. При новой разборке того же источника (v2.0, обновлённая редакция) — новый файл
   рядом; старый остаётся.
3. Если содержимое источника было чувствительным и не должно быть публичным —
   не архивируем, удаляем оригинал; сохраняем только memo без содержимого.
